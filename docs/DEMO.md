# 40秒演示素材脚本

脚本已准备，视频尚未录制。只展示实际已有的功能；历史价格必须保留回放标识与时间。

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0—7秒 | examples/replacement.recipe.json中的预算和餐品目标 | 朋友分享的一顿，在我的门店还能照着吃吗？麦麦复刻分享目标和允许替代。 |
| 7—17秒 | 已安装技能的对话：导入、确认预算与候选、选择本人门店 | Agent重新查询当前门店，根据我接受的候选生成请求，再用麦当劳MCP整单核价。 |
| 17—28秒 | docs/assets/result-overbudget.png中的历史结果卡 | 首选33.50元，接受的替代34元；33元内没有达标方案，程序如实停下。 |
| 28—35秒 | 默认工作区生成结果卡的过程；隐藏个人信息 | 结论、餐单变化、价格和未知项分开展示。服务端没有回显的选配，不靠价格猜。 |
| 35—40秒 | downloads/meal-share.zip中的card.md和meal.recipe.json | 把目标分享给朋友，让他的Agent按自己的门店重新查。当前只读核价，不下单。 |

展示前隐藏精确门店、追踪号、订单号、账号和凭据。不得把录制时的模拟称为本轮真实调用，也不声称今日心情餐、自动下单或持续复用已完成。
